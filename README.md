# ASCENT — Scale-Complementary External State for Frozen Long-Context Language Models

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22865846.svg)](https://doi.org/10.5281/zenodo.22865846)

Code, frozen configurations, per-row experimental records, and audit
documents for the manuscript *ASCENT: Scale-Complementary External State for
Frozen Long-Context Language Models* (Xingjian Zhang; Array, Elsevier,
manuscript ARRAY-D-26-05300 — under revision). ASCENT writes a bounded,
target-blind, query-conditioned external state from a long input before the
question is revealed and lets a frozen reader answer from that state; the
paper asks whether the benefit of such state grows with reader scale and
reports pre-registered, panel-clustered evidence on BABILong and RULER for
Qwen2.5 readers from 0.5B to 7B, plus a numeric factorial that isolates the
reader-by-state interaction.

## Quick verification (CPU, ~10 seconds, no model weights)

Requires Python 3.10 or newer. The exact NumPy/SciPy pins apply on Python 3.12+; on 3.10–3.11 the requirements file selects the latest compatible releases, and the same checks pass (tested on 3.10–3.13 on Linux and on 3.12 on macOS).

```sh
git clone https://github.com/XingjianZhang-dev/ascent.git && cd ascent
python3 -m venv .venv && source .venv/bin/activate
pip install -r reproduction/requirements-reproduce.txt
make reproduce
```

This re-verifies the SHA-256 manifests of the result trees, recomputes the
four authoritative analysis files from the retained per-row records,
re-renders every generated manuscript table byte for byte, and prints every
reported number. Expected last line:

```
ALL REPORTED NUMBERS REPRODUCED
```

A transcript from a fresh clone is in
`reports/FRESH_CLONE_REPRODUCTION_TRANSCRIPT.txt`. `make test` runs the unit
tests (tests that need withheld benchmark row bodies or a GPU stack report as
skipped, not passed).

## What is and is not redistributed

- **Included:** all source code; all frozen configurations; every retained
  result record and analysis file that the manuscript's numbers derive from;
  the revision-stage records; panel manifests, per-row identifiers and hashes
  sufficient to rebuild every evaluation panel from the pinned upstream
  revisions with the construction scripts in `experiments/`; synthetic panels
  generated by this project.
- **Not included:** benchmark row bodies (BABILong inputs and RULER task
  files — mixed upstream licences, see `THIRD_PARTY_NOTICES.md`); model
  weights (revisions and shard hashes are pinned in `configs/`); four result
  archives that embed row bodies (listed with hashes in `VERIFICATION.md`
  §9); the 275 MB frozen backup of the final compute instance (SHA-256
  `431049c38a3c91e7b0fb1f8a3d5a52484aeae609a81a12af0c9c5272a5e00821`,
  available to the editor on request).

Provenance fields in retained artifacts record the original development
environment paths. These files are published unmodified so that their
recorded SHA-256 values remain verifiable.
